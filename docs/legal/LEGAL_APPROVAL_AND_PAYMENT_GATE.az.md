# Hüquqi qərar və ödənişli paketlər üzrə buraxılış qapısı
**QƏRAR SƏNƏDİ — YALNIZ TƏSDİQLƏNDİKDƏ QÜVVƏYƏ MİNİR**

## Rəsmi təsdiq tələb edən qərarlar
1. ADNSU və ya digər hüquqi şəxsin platformanın sahibi/operatoru olmasının təsdiqi.
2. “Fərdi məlumatlar haqqında” qanunun 8 və 15-ci maddələri üzrə razılıq forması və informasiya sisteminin qeydiyyatı/tətbiq edilən istisnası barədə yazılı rəy.
3. “Məşğulluq haqqında” Qanunun 14-cü maddəsi və işədüzəltmə vasitəçilərinin reyestri üzrə tətbiqin təsnifatı.
4. Vercel / Supabase / AI provayderləri və transsərhəd məlumat axınları üzrə razılaşdırma.
5. Şirkət müqaviləsinin, məlumat təhlükəsizliyi öhdəliklərinin, ödəniş və qaytarma qaydasının təsdiqi.
6. Çıxarılan bütün hüquqi mətnlərin versiya, qüvvəyə minmə tarixi, təsdiq edən şəxs və arxiv qeydlərinin saxlanması.

## Ödənişli paket üçün bloklayıcı testlər
- Free / Pro / Business qiymət və limitlərinin faktiki backend ilə uyğunluğu.
- Ödənişin hüquqi benefisiarı və rəsmi hesablaşma tərəfi müəyyən edilib.
- Müştəriyə müqavilə, hesab-faktura/çek, xidmət şərtləri, ləğv və geri ödəniş forması göstərilir.
- Müqavilə qeydi olmadan avtomatik ödəniş başlatmaq olmaz.
- Ödəniş provider webhook-ları imza ilə yoxlanmalı, idempotent olmalı, paket yalnız təsdiqlənmiş ödənişdən sonra aktivləşdirilməlidir.
- Admin üçün manual paket aktivasiyası və audit qaydası olmalıdır.
