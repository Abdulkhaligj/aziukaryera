# ADNSU Karyera — İstifadə şərtləri (LAYİHƏ)
**Hüquq şöbəsi təsdiqləyənədək dərc edilmir.** Versiya 0.1, 25.10.2026.

1. **Xidmətin mahiyyəti.** Platforma tələbələri, məzunları və işəgötürənləri karyera imkanları haqqında məlumatlandırmaq, müraciətlərin idarəsini asanlaşdırmaq üçün hazırlanmışdır. İş təklifi və işə qəbul zəmanəti verilmir. Faktiki fəaliyyətin işədüzəltmə vasitəçiliyi sayılıb-sayılmaması ayrıca yazılı hüquqi rəy tələb edir.
2. **Hesablar.** İstifadəçi yalnız öz hesabından istifadə edir, düzgün məlumat verir, giriş məlumatlarını başqasına ötürmür. Rollar və məzmun hüquqları server tərəfində yoxlanılır.
3. **Vakansiyalar.** Elanın iş şərtləri, əlaqə məlumatları və işəgötürən barədə iddialar onu yayımlayan şirkətin öhdəliyidir. Platforma şübhəli elanları dayandırmaq və araşdırmaq hüququnu saxlayır; bu qeyd platformanın qanuni vəzifələrini aradan qaldırmır.
4. **Qadağan olunan davranış.** Ayrı-seçkilik, saxta elan, namizəd məlumatlarının icazəsiz satışı, yığılması, üçüncü tərəfə ötürülməsi, istismar və təhlükəsizlik maneələrinin aşılması qadağandır.
5. **Şəxsi məlumatlar.** Məlumatların işlənilməsi Məxfilik siyasəti və tətbiq olunan qanunvericilik əsasında aparılır. Şirkətə müraciət və profil paylaşımı ayrıca nəzarət olunur.
6. **AI imkanları.** AI-nin CV üzrə rəyi avtomatlaşdırılmış yardımçı nəticədir; yekun seçim, imtina və ya qiymətləndirmə üçün yeganə əsas kimi istifadə olunmamalıdır.
7. **Şikayət.** İstifadəçi saxta vakansiya, hüquq pozuntusu və ya məlumatların qanunsuz işlənilməsi ilə bağlı **[RƏSMİ ƏLAQƏ KANALI]** vasitəsilə müraciət edə bilər.
8. **Abunə/ödənişlər.** Şirkət paketləri aktivləşdirilməzdən əvvəl ayrıca kommersiya şərtləri, ödəniş proseduru, faktura və geri ödəniş mexanizmi təsdiqlənməlidir. Ödənişin olmaması və ya admin təsdiqi tələb olunması açıq göstərilməlidir.
9. **Dəyişiklik və hüquqi tərəf.** Xidmətin rəsmi operatoru, müqavilə tərəfi, hüquqi ünvan, mübahisələr və qüvvəyə minmə tarixi **[HÜQUQ ŞÖBƏSİ TAMAMLAMALIDIR]**.

**Qeyd:** Hazırkı layihə hüquqi məsuliyyəti birtərəfli və ya qeyri-məhdud qaydada ləğv edən bəyanat kimi istifadə edilməməlidir.
