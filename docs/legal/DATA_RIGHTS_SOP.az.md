# Şəxsi məlumatlarla bağlı müraciətlərin idarə edilməsi — daxili prosedur
**Daxili işçi layihədir; hüquq şöbəsinin təsdiqi tələb olunur.**

## 1. Qəbul
Müraciət növü: məlumatlarımın surəti, düzəliş, silinmə, işlənməyə etiraz, paylaşım icazələrinin yoxlanması, təhlükəsizlik şikayəti.
Minimum toplama: müraciət növü, hesab identifikatoru, müraciətin tarixi; əlavə həssas sənəd tələb etməyin. İstifadəçinin şəxsiyyətini ayrıca təhlükəsiz qaydada yoxlayın.

## 2. Qeydiyyat
Daxili iş nömrəsi, alınma vaxtı, hüquqi əsas, məsul şəxs, müddət, görülən tədbir, cavab və bağlanma tarixini əməliyyat jurnalına daxil edin. Müraciət mətnini bildirişlərə və açıq analitikaya verməyin.

## 3. Nəzarət
Müraciətə baxan admin yalnız roluna uyğun məlumat görməlidir; səlahiyyətli hüquq nümayəndəsi həssas qərarları təsdiq edir. Müddətləri qanunun tətbiq olunan norması üzrə hüquq şöbəsi rəsmiləşdirməlidir — burada təxminən gün sayı qoyulmur.

## 4. İcra
Məlumatın mənbələrini və üçüncü tərəfə ötürülməsini qiymətləndirin; hüquqi saxlanma və mübahisə səbəbi varsa silinmənin məhdudiyyətini ayrıca əsaslandırın. Silinmə həm tətbiq məlumatlarını, həm də ehtiyat nüsxələrdə saxlanma siyasətini nəzərə almalıdır.

## 5. Cavab və bağlanma
İstifadəçiyə görülən tədbirlər, qanuni məhdudiyyətlər, şikayət imkanı və əlaqə qaydası barədə təsdiqlənmiş kanalla cavab verin. Yalnız zəruri audit məlumatları saxlayın.

## 6. Məlumat təhlükəsizliyi hadisəsi
Təsiri dərhal məhdudlaşdırın, məlumatların təsirlənmə miqyasını yoxlayın, təhlükəsizlik və hüquq şöbəsinə eskalasiya edin; bildiriş öhdəliklərini qanunla müqayisə edin. Hadisə üzrə real istifadəçi və ya məxfi CV nümunəsini açıq issue tracker-ə yerləşdirməyin.
