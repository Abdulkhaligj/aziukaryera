# Funksiya siyahısı

## Tələbə və məzun

- ayrıca tələbə qeydiyyatı;
- Bachelor, Master və Graduate/Alumni seçimləri;
- çoxsaylı təhsil qeydləri;
- vakansiya və imkanların filtrlənməsi;
- saxlanmış imkanlar və müraciətlər;
- CV qurucusu, CV təhlili və müsahibə hazırlığı;
- şəbəkə paylaşımları və qarşılıqlı əlaqə;
- bildiriş və profil idarəetməsi.

## Şirkət

- ayrıca şirkət qeydiyyatı və admin təsdiqi;
- FREE, PRO, BUSINESS paket seçimi;
- paket üzrə real backend limitləri;
- geniş vakansiya formu və təsdiq növbəsi;
- müraciət pipeline-ı və tarixçə;
- paketə görə namizəd axtarışı, media, paylaşım və komanda hüquqları;
- abunəlik və istifadə göstəriciləri.

## Admin

- tələbə, magistr, məzun, şirkət və vakansiya CRUD;
- şirkət və vakansiya təsdiqi;
- paket, abunəlik və ödəniş görünüşü;
- şəbəkə moderasiyası;
- bildiriş, AI istifadəsi və audit tarixçəsi;
- maksimum 5 admin hesabı;
- Super Admin üçün qorunan sistem sıfırlaması;
- əsas statistika və fəaliyyət göstəriciləri.

## Platforma

- bir Supabase Auth və PostgreSQL bazası;
- RLS və foreign key-lər;
- SQL migrations;
- backend trigger-lərlə limit yoxlaması;
- responsive desktop, tablet və mobile görünüş;
- private GitHub və ayrıca Vercel layihələri üçün deployment quruluşu.

## Xarici konfiqurasiya tələb edən hissələr

- AI provayderinin real generativ cavabları üçün Gemini və ya Groq secret-i;
- avtomatik ödəniş almaq üçün seçiləcək provayderin checkout/webhook adapteri.

Bu secret-lər repozitoriyaya daxil edilmir. Manual paket təyin və uzatma admin panelində saxlanılır.
